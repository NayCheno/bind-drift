BindDrift prioritizes review targets for Rust-for-Linux cross-language API and
contract drift. \tool{} is a static-analysis and cross-version replay framework
that prioritizes evidence-backed review targets for Rust-for-Linux API and
contract drift. It does not prove Rust abstraction soundness or automatically
confirm runtime bugs. The current artifact separates low-level cross-version
drift facts from promoted Rust-impact warnings, attaches a C-to-Rust evidence
chain, and ranks warnings for maintainer review. The canonical replay spans 21
Linux snapshots, 20 adjacent version pairs, 16,757 drift facts, and 320
promoted Rust-impact warnings. An 800-item pooled review set follows a trusted
binddrift-review expert protocol with role separation, double review, and
adjudication. The primary
